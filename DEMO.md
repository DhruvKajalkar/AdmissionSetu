# AdmissionSetu Demo Walkthrough

Use this path for a short, reproducible judge demo.

1. **Reset Demo.** Use the compact control above any citizen page and confirm. Point out that preferences are preserved.
2. **Dashboard.** Aarya holds AISSMS Computer Engineering through CAP Round II with Betterment active. Show CET/JEE context and the one-current-seat card.
3. **College Explorer.** Search `0627137210` to show PICT ENTC. Point out the official CET reference label, choice code, intake and sourced historical cutoff.
4. **My Preferences.** Show the top-six Round III auto-freeze zone. Mark a top-six choice **I'm not sure**, run **Review preference safety**, and explain the caution. Return without changing the final order if time is short.
5. **Live Vacancies.** Find AISSMS Computer Engineering and record **2 demo seats available**. Explain that counts come from the shared synthetic seat inventory, not an official CET vacancy feed.
6. **Spot Rounds.** Show active, upcoming and completed rounds, the 0/5 interest count and the PICT/VIT schedule-overlap explanation.
7. **Join PICT ENTC.** Open the live round. Confirm the starting state: **2 seats**, **position 7**, **4 candidates ahead**.
8. **Advance the demo.** Select **Advance Demo Event** five times. Narrate the queue movement and point out the PICT vacancy event **2 → 3**.
9. **Review the offer.** Compare **Current seat: AISSMS Computer Engineering** with **New seat: PICT ENTC**. Explain that acceptance releases the previous seat and closes other active spot interests.
10. **Accept.** Select **Accept Seat**, then **Confirm Acceptance**.
11. **Show the result.** The success view identifies PICT as the new admission, AISSMS as released and AISSMS vacancies as **2 → 3**.
12. **Cross-check state.** Open **Dashboard**, **My Admission**, **My Preferences**, **Live Vacancies** and **Spot Rounds** to show that every page agrees.
13. **Reload.** Hard reload the page; the accepted state remains on this device.
14. **Reset for the next judge.** Use **Reset Demo**. Confirm AISSMS is current again, AISSMS vacancies return to 2, spot progress returns to zero and the saved preference count is unchanged.

Presenter note: every candidate, vacancy, queue, offer and deadline in the live journey is synthetic. Institute, programme, intake and displayed historical cutoff references are labelled official CET reference data.
